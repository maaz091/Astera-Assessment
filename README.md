# Studio foundation

Run `npm install`, then `npm run dev`. Build with `npm run build`; serve the generated `out/` folder with any static HTTP server. Routes: `/`, `/style-guide/`, `/components/`.

Chat supports regional targets and monthly sales in Q2/Q3 2026. Answers use fictional canonical fixtures. Pins and conversation persist locally. Data trail explains the initial failed Join while retaining successful data. Dashboard and Pipeline Detail are intentionally deferred; their navigation is disabled. No backend or real AI calls.
