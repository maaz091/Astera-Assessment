# Studio foundation

Run `npm install`, then `npm run dev`. Build with `npm run build`; serve the generated `out/` folder with any static HTTP server. Routes: `/`, `/dashboard/`, `/style-guide/`, `/components/`.

Chat supports regional targets and monthly sales in Q2/Q3 2026. Answers use fictional canonical fixtures. Pins and conversation persist locally. Data trail explains the initial failed Join while retaining successful data. Dashboard includes scoped KPIs, regional and monthly charts, period/region filters, and Saved from Chat with persistent unpinning. Overview filters are stored in the URL and do not alter saved answer scopes. Pipeline Detail is deferred; its navigation remains disabled. No backend or real AI calls.
